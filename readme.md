
# FRAME – Photography Gallery

A professional and responsive photography gallery developed as part of the CodeAlpha Frontend Development Internship.

## Project Description

FRAME is a modern image gallery website designed with a minimal editorial style and muted color palette.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive image gallery
- Category-based filtering
- Image search
- Full-screen lightbox
- Next and Previous navigation
- Keyboard controls
- Favorite images
- Local Storage support
- Mobile-friendly design

## Project Structure

- index.html – Website structure
- style.css – Website styling
- script.js – Interactive functionality
- README.md – Project documentation

## How to Run

1. Clone or download the repository.
2. Open the folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Explore the gallery.
